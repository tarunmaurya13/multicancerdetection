About this demo

This single page app is a frontend-only demonstration. To make it work with a real model, expose an API endpoint (e.g. POST /api/predict) that accepts an image file and returns JSON with predicted class names and confidence scores.

Quick instructions

  1. Upload an image (histopathology or scan).
  2. Click Predict to run the demo.
  3. Replace the mockPredict() function with a real fetch to your server.
